# Web Games

Small experimental casual games made with HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, or serve the repository directory locally:

```sh
python3 -m http.server
```

Then visit <http://localhost:8000>. The arcade currently includes Star Catch, a
20-second reflex game, and Light Sequence, a pattern-memory game. No build step
or package installation is required.
